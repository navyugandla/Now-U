# DataEasy

A clean, beginner-friendly data science workspace inspired by the supplied DataEasy design.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Git

This folder is already initialized as a Git repository.

```bash
git add .
git commit -m "Build DataEasy data science app"
```

To publish it to your own GitHub repository:

```bash
git remote add origin YOUR_GITHUB_REPO_URL
git branch -M main
git push -u origin main
```
